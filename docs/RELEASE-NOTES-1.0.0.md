# Deskriptions 1.0.0

Deskriptions is a free, open-source macOS menu-bar application for pinning live window previews and saving collections of supported applications and content as Desktops.

Version 1.0.0 includes live ScreenCaptureKit previews; Desktop save and restore for supported Chromium browser windows and tabs, Finder folders, Preview documents, selected Apple Notes, and application-only entries; configurable global shortcuts; local diagnostics; retention controls; and recovery for interrupted preview and restoration operations.

Saved Desktop format v1 and adapter protocol v1 are unchanged from the 0.11.1 release candidate. Existing saved Desktops, settings, browser identities, and profile associations remain compatible.

Live-preview updates still depend on the source application continuing to render. Deskriptions does not manage macOS Spaces or reproduce arbitrary application state and unsaved work. See `KNOWN-ISSUES.md`, `COMPATIBILITY.md`, and `TESTER-GUIDE.md` for current limitations and setup instructions.
