# Deskriptions 1.0.2 development build

- Repairs the Extensions Settings inventory so built-in integrations and live, stale, incompatible, disconnected, and previously configured browser extensions remain visible with accurate status.
- Adds document-aware Apple Preview capture and restoration using exact Accessibility `AXDocument` file URLs, explicit Preview opening, and post-open verification.
- Preserves format-v1 saved Desktops; older Preview records decode with their original Preview application identity.

This development package is not a new public release and is not notarized by the build workflow.
