# Deskriptions 1.0.8 development build

- Shows Save Desktop immediately while inventory is collected safely in the background.
- Prevents saving until all inventory sources complete or time out.
- Deduplicates PowerPoint by stable application and standardized document identity.
- Reuses the native transient status banner for slow inventory, save, load, partial, and failed operations.
- Bounds unresponsive PowerPoint Automation inventory calls to eight seconds and reuses very recent results.
- Finds additional PowerPoint presentations through bounded exact-URL Accessibility hierarchy discovery when AXWindows exposes only the focused file.
